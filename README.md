# Zhevion

An offline-first workout tracker built with Flutter to help you plan, log, and monitor your training.

---

## ✨ Features

- 🏋️ Powerlifting-focused workout planning
- 📅 Organize programs by weeks and training sessions
- 📚 Comprehensive exercise library
- 📈 Track sets, reps, weight, RPE, and personal records
- 🎯 Built for progressive overload and strength progression
- 💾 Offline-first with Isar database
- ⚡ Fast and responsive experience
- 🌙 Material 3 design with Dark Mode

## 🚀 Installation

1. Download **Zhevion-v1.0.0.apk** (or the latest version).
2. Install the APK.
3. If Android asks, allow installation from unknown sources.
4. Launch **Zhevion**.
