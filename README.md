# Zhevion

An offline-first workout tracker built with Flutter to help you plan, log, and monitor your training.

---

## ✨ Features

- 💪 Create unlimited workout programs
- 📅 Organize workouts by weeks and sessions
- 🏋️ Exercise library
- 📈 Track sets, reps, weight, and RPE
- 💾 Offline-first with Isar database
- ⚡ Fast and responsive UI
- 🌙 Material 3 with Dark Mode

## 🚀 Installation

1. Download **Zhevion-v1.0.0.apk** (or the latest version).
2. Install the APK.
3. If Android asks, allow installation from unknown sources.
4. Launch **Zhevion**.
